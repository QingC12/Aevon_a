## 本次清理

1. 删除 `GestureRules.h`、`test_gesture_rules.c`：它们在 2.0.14 中已只是两行／一行注释占位，并非仍在运行的手势实现。
2. 删除 `KeyboardInsetMath.h`、对应旧测试及无用导入：旧窗口相交公式没有生产调用；当前 scene 坐标、物理键盘平面和输入组件路径保留。
3. 删除未参与生产编译的旧 `EditorVisibility.m`。活动入口仍在 `EditorPolicy.m`；`EditorVisibilityMath.h` 仍被实际使用，因此保留。
4. 删除没有调用或动态查找的 `_STHNativeAnimatePhysicalKeyboard` 及其私有闭包；删除只有旧测试调用的 `STHKeyboardCenterDelta`。正常显示／隐藏、原生动画入口、缩放／位移及手势桥保留。
5. 删除构建脚本闲置导入、已完成用途的一次性补丁脚本；忽略 Python 缓存、目标文件和构建输出。历史包、审查证据、原版输入和回归测试保留。

这些删项多数原本就不进入安装包，源码目录变整洁不代表能大幅缩小运行库或提升运行速度；本版没有作这类性能承诺。

## 明确保留

- 全部原版设置开关、界面资源、默认值及功能分支；不隐藏拦截、静默、前台通知等选项，不硬编码关闭任何原开关。
- 原版安装／卸载脚本、组件过滤 plist、相机和键盘 companion、私有 Orion 及许可证。
- QQ／Minis 兼容路径、微信 refined 路径、威锋／酷安／抖音 composite 路径。
- 当前活动的 `LayoutProbe` 视图几何探针、跨进程布局通道和只读 `NotificationPolicy` 诊断。它们有实际调用，不是失效工具。
- 正常手势判断、窗口默认尺寸和原动画入口。

这里的“无损”指同次构建压缩前后的 TAR 相同，不表示 2.0.15 与 2.0.14 的整个安装负载都相同。未采用尚无链接图／设备回归依据的死符号裁剪、原版 Swift/Objective-C 元数据剥离或模块删除。

## 全局审查发现

### 已确认的旧安装风险：本版保留原行为

原 `postinst` 在某些模板／激活内容及大小检查不满足时，会复制整份默认偏好文件。这条路径可能重置已保存的 `SettingMask`、应用列表等配置。后续逐键设置不是完整的偏好合并。原 `postrm` 对备份的覆盖式恢复也没有严格区分升级与卸载回调。

本版安装脚本与旧包完全一致，**没有实施偏好迁移，也没有宣称已经修好这些旧风险**。修复应独立安排备份、按键合并及升级／卸载回归，避免混入这次键盘定档维护。

### 仍需单独验证的映射与组合

- 原版 `SthenoCamera`／`CameraFix`、`SthenoKeyboard`／`KeyboardFix` 存在目标进程重叠；具体加载顺序、独立 fallback 和总开关传播行为尚未完成设备组合验证。
- 部分 UI → 存储位 → 每个消费者的映射未完全闭合；这不构成删除它们的依据。
- 新手势模块直接读 bit 16，是否应纳入原版每应用覆盖语义仍待确认，本版未更改。
- `ForegroundNotify` bit 27／`FrontmostNotify` bit 28 都不是系统声音总开关。默认模板与实际用户保存值是不同证据；本版未更改声音、静音、专注模式或通知权限。

## 验证范围

- CI 的手势路由、键盘几何／会话、重复呼出、不可变通知、布局通道、组合输入容器及原生布局盾等既有回归全部通过。
- 新维护测试在 CI 和下载后的真实制品上均通过：精确文件清单、原设置资源、默认 mask、安装脚本、压缩长度和解包哈希完整。
- 独立复算 **11 个 arm64e Mach-O 的代码页签名全部通过**。
- 私有 Orion 的 **79 个导入全部解析**，许可证保留，无外部 Orion 包依赖。
- 主库补丁指令与动态加载路径通过独立检查。
- 构建仍有原键盘窗口枚举的 `UIApplication.windows` 弃用警告；它不是构建失败，本版未为消除警告改变定档行为。

**尚未进行本版真机安装验证。** 原版完整 Swift 源码并未恢复，静态盘点和主机回归不等同于对所有 iOS 私有层级、进程时序和开关组合的完整证明。

为了保持冻结二进制，模块日志仍可能显示 `2.0.14` 或通知诊断的 `2.0.13` 标签；软件包的真实版本以 DEB control 中的 `2.0.15` 为准。
